# ClaudeCodex

A workspace for coordinating cloud agents and local models.

Coordinate development tasks through staged workspaces, agent handoffs and reviewable changes. The owner controls account access and decides when changes are applied.

## Technologies

Python · React · TypeScript · Local models

## What it does

- Explicit laptop-folder import and PC workspaces
- Staged development with review, Apply and Undo
- Task activity, changed files and read-only Git status

## Current status

Local development workspace; not a public hosted agent service.

Full implementation remains private. This showcase contains descriptions and approved demonstration material only.
